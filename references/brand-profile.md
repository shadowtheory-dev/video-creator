# The project's brand profile (VIDEO-BRAND.md)

The skill stays brand-agnostic; each project keeps one file, `VIDEO-BRAND.md` at its root (or wherever its CLAUDE.md points), that every film session reads first. Write it from the brand's own docs the first time a project makes a film; keep it short and point to sources rather than copying them.

```markdown
# <Brand>: video profile

## Sources (read these, they win)
- Brand rules / guidelines: <paths>
- Tokens, type, motion, sonic rules: <paths>
- Copy: <positioning, tone, facts files>
- Project rules: <CLAUDE.md, memory notes>

## Look
- Palette and what each colour means (e.g. the one accent = the product)
- Type: faces, roles, weights; the lockup rules (mark position, never stacked)
- Drawing language: illustration/iso style, line weights, plates, materials
- Surfaces and effects the brand owns (e.g. a dithered gradient surface, glass)
- Never: <the brand's bans>

## Voice
- Who the films speak to; words to use and avoid
- Approved lines and where they come from

## Sound
- Tempo range, key, payoff and sonic logo, loudness; deviations the user approved

## Assets and tools
- Logo files, fonts (local paths), image/footage libraries with credits, sound banks
- Track editor, render tools, earlier films to learn from (with folders)

## Where things go
- Film folders, outputs folder (not in git), review pages, research folders
- Git rules (commit by path, never video), publishing rules
```
